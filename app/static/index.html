HOW IT WORKS

Built for verifiable answers

HYBRID SEARCH

Vector + keyword fusion

Combines semantic vector similarity with full-text search using Reciprocal Rank Fusion so both exact terms and concepts rank accurately.

RERANKING

Cross-encoder filtering

Scores candidate chunks with a cross-encoder and abstains when no document contains sufficient evidence.

VERIFIED CITATIONS

Sentence-level quotes

Every [n] citation is matched against the source chunk sentence to surface the exact supporting quote.
