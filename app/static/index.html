How It Works

HYBRID RETRIEVAL

Vector + Keyword Fusion

Combines semantic vector similarity with full-text search using Reciprocal Rank Fusion so both exact terms and concepts rank accurately.

RERANK & ABSTAIN

Cross-Encoder Filtering

Scores candidate chunks with a cross-encoder and automatically abstains when no document contains sufficient evidence.
