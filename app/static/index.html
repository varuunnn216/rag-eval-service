Built for Verifiable Precision

HYBRID RRF (k=60)

Dense pgvector + Sparse FTS

Fuses 768-dim L2-normalized cosine similarity with PostgreSQL English websearch_to_tsquery cover-density ranking so both exact terms and semantic concepts surface at #1.

CONTEXT GATE

Cross-Encoder Rerank Filtering

Applies ms-marco-MiniLM-L-6-v2 with a calibrated minimum floor (0.25), relative ratio cutoff (0.60 × top), and content-hash deduplication before LLM generation.

CLAIM VERIFICATION
